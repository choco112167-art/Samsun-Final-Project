## 4. Permissions And User Data

| Device permissions | No camera, location, contacts, microphone, or photo permissions requested. |
| Toss login | Not used. |
| In-app payment | Not used. |

The frontend uses the Supabase anon key only. Service-role keys are kept in backend/server-side scripts and must never be bundled into `.ait`.

## 5. Privacy / Sensitive Information

The app displays public AI/tech news articles stored in Supabase. It does not ask the user to enter resident registration numbers, payment data, medical data, contact lists, precise location, or other sensitive personal information.

Local state used by the app:

- Tone preference: `격식체` / `일상체`
- Local bookmark/view helper data
- Apps in Toss device ID or browser fallback ID for local personalization

## 6. External Links / Source Links

The article detail page provides `원문 보기` for the original source URL.

Implementation evidence:

- `frontend/src/lib/toss.ts`: `tossOpenURL()` uses Apps in Toss `openURL()`, with browser fallback.
- `frontend/src/pages/DetailPage.tsx`: validates `http://` / `https://` URLs before opening.

The translation section and original source link are separate. The app does not replace translated content with the source URL.

## 7. Loading / Empty / Error States

The app includes user-visible states for:

- Missing Supabase environment variables.
- Supabase article query failure.
- Zero articles returned.
- Missing or generating summaries.
- Missing or generating full translation.
- Missing source URL.
- Optional neologism lookup failure, which does not block article rendering.

Implementation evidence:

- `frontend/src/data/api.ts`
- `frontend/src/lib/supabase.ts`
- `frontend/src/pages/HomePage.tsx`
- `frontend/src/pages/DetailPage.tsx`

## 8. Mobile UI / Navigation

Samsun News is mobile-first:

- Fixed-width mobile app shell.
- Safe bottom padding for floating tab navigation.
- Touch-friendly buttons and bottom sheets.
- No desktop-only layout required for the main experience.
- Detail page has its own back button, but final Apps in Toss test should verify that it does not conflict with the Toss navigation bar.

Real-device QA points:

- First screen loads without an auto-open bottom sheet.
- Back action returns from detail to feed.
- First-screen back exits the mini-app through Toss navigation.
- Scrolling, tab switching, summary tone toggle, and bottom sheets respond without long delay.

## 12. Toss Console Test Registration And Demo Procedure

1. Open the Apps in Toss Console.
2. Select the `samsun-newsapp` app.
3. Go to the test/release upload area.
4. Upload `frontend/samsun-newsapp.ait`.
5. Register the test build and open it from the Toss app on a real device.
6. Confirm the navigation bar shows `삼선뉴스` and the brand icon.
7. Run the demo flow:
   - Home feed loads Korean-first article cards.
   - Open article detail.
   - Toggle `격식체` / `일상체`.
   - Expand `번역 전문`.
   - Check fact badge.
   - Tap highlighted neologism and confirm bottom sheet explanation.
   - Tap `원문 보기` and confirm the original link opens.
   - Return to feed.
